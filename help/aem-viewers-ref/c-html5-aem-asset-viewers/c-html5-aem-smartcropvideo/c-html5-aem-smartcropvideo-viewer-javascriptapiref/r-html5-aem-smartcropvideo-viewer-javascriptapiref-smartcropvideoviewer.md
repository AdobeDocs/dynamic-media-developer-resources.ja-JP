# SmartCropVideoViewer{#smartcropvideoviewer}

スマート切り抜きビデオビューアのJavaScript API リファレンス。

`SmartCropVideoViewer([config])`

コンストラクター。スマート切り抜きビデオビューアーインスタンスを作成します。
